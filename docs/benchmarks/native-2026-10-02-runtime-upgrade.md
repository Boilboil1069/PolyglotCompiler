## 协议与解读

- 9 种语言 × 6 个工作负载 × O0/O1/O2/O3，共 216 配置。工作负载为嵌套调用、循环与分支、递归、8/64/256 个辅助函数。使用默认 linear-scan 分配器。
- 每次编译写入新路径，使用严格模式并关闭包索引和辅助产物。检查原生文件头，然后实际启动产物，核对退出码、stdout、stderr。完整数字与运行时 API 的正确性另由语义差分与运行时回归覆盖。
- 编译时间包含驱动、前端、中间层、后端、目标文件输出与 polyld 链接。保留自然文件缓存，不复用上轮编译产物。配置按固定顺序运行。
- 短程序运行耗时包含首次启动新 Mach-O 产物的系统开销，不代表计算吞吐。长内核的运行性能见独立优化实验。
- 数据记录当前版本的绝对耗时。初版基线的实现和代码生成不同，且不是随机交错的同场对照，本报告不据此宣称编译速度提升。

## 复现

```bash
python3 scripts/benchmark_native.py \
  --polyc build-release/polyc \
  --output build-release/native-evaluation/runtime-upgrade-rerun \
  --opt-levels 0 1 2 3 --scales 8 64 256 \
  --warmups 1 --repetitions 7 --timeout 30
```

输出目录必须不存在，以免覆盖旧样本。
