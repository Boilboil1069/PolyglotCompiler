# Iris data provenance

`source/bezdekIris.data` is the corrected Iris source distributed by the UCI
Machine Learning Repository. Its SHA-256 is
`0fed2a99db77ec533a62dc66894d3ec6df3b58b6a8f3cf4a6b47e4086b7f97dc`.

- Dataset page: <https://archive.ics.uci.edu/dataset/53/iris>
- DOI: <https://doi.org/10.24432/C56C76>
- License: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/)
- Creator: R. A. Fisher; UCI donor: Michael Marshall

`iris_q10.csv` is a deterministic derivative generated by
`tools/prepare_iris.py`. Every measurement is multiplied by ten, the first 40
rows of each class form a 120-row training split, and the remaining ten rows
of each class form a 30-row test split. Rows are class-interleaved within each
split so every 12-row training batch is balanced.

The CSV header intentionally contains no digits. The compiler's tiny native
integer scanner skips text but parses every decimal integer it encounters.
